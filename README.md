# 日语用言活用自主训练

这是面向大学生日常自主练习的免费静态网页工具，不需要注册账号，也不需要下载安装软件。

- 正式网站：https://kinyo-dong.github.io/japanese-conjugation/
- 部署方式：GitHub Pages（`main` 分支根目录）
- 当前版本：`2026.11-security`

## 主要用途

平台用于练习日语动词、形容词、形容动词及名词谓语的活用，包含指定活用、混合练习、自动批改、答案解析、错题复习、自建词汇和学习记录等功能。

## 隐私与数据

本项目是纯静态网页：

- 不设置学生账号；
- 不接入广告或统计跟踪；
- 不把答题记录发送到服务器；
- 学习记录、自建词汇和错题记录仅保存在学生当前浏览器的本地存储中；
- 不同设备、浏览器及微信内置浏览器之间不会自动同步，可通过页面内的备份与恢复功能手动迁移。

请勿在自建词汇、答题或备份文件中填写姓名、学号、联系方式等个人敏感信息。

## 安全设计

当前版本不加载第三方 JavaScript，不使用 iframe、Service Worker 或浏览器权限请求，并通过内容安全策略限制外部连接。TXT/CSV 词表导入和 JSON 备份恢复设有格式、大小、数量及字段校验。用户输入在显示前进行 HTML 转义。

这些措施用于降低常见风险，但不构成“绝对安全”保证。发现异常时，请停止使用并通过仓库 Issues 报告。
